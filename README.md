# 🌐 WanderClick Randomly

A small web project that lets you discover random and fun websites around the internet.

When you click **Explore the Web**, JavaScript randomly selects a website from the list and opens it in a new tab.

The user:
1. Opens the website.
2. Clicks the Explore the Web button.
3. JavaScript randomly selects a website.
4. The selected website opens in a new tab.
5. The user starts a small internet adventure.
